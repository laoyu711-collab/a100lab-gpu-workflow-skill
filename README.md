# A100 Lab GPU Workflow Skill

面向课题组普通用户的 GPU 开发与运行技能，帮助智能体按照服务器的 Slurm 规则编写代码、提交任务并检查结果。

## 适用场景

需要使用本服务器 GPU 进行训练、推理、评测或调试时，在编写、修改或运行相关代码前加载本技能。纯 CPU 任务和仅调用远程模型 API 的任务不适用。

## 主要内容

- 服务器环境、short/normal 调度等级与抢占规则。
- 代码和环境适配、日志、错误处理及 checkpoint 恢复。
- GPU、CPU、主机内存和运行时长申请。
- Slurm 作业脚本示例、提交、状态查询与结果验收。

## 使用方式

将技能安装到**当前用户的全局技能目录**，使其在该用户的各个项目中均可使用。以服务器上的 Claude Code 为例，文件位置为：

```text
~/.claude/skills/a100lab-gpu-workflow/SKILL.md
```

`~` 表示当前服务器用户的主目录。创建 `a100lab-gpu-workflow` 子目录，将本仓库的 [SKILL.md](./SKILL.md) 下载到其中，保留文件名；无需复制 README。安装后重新启动 Claude Code，可通过 `/a100lab-gpu-workflow` 显式调用，也可由智能体根据 GPU 任务需求加载。

其他智能体请使用其支持的个人全局技能目录。

使用前需已取得服务器账号及 Slurm 提交权限。具体操作与限制以技能正文和服务器当前配置为准。

## 更新

最新版本维护于本仓库的 `main` 分支。技能默认每隔 3 天在被使用时提醒检查更新，不是后台定时通知；更新前保留本地备份。周期可在 `SKILL.md` 中调整。
